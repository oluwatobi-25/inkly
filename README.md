# Inkly

**Turn your handwriting into a font you can actually use.**

Inkly is a web-based handwriting-to-font tool that lets you draw your own characters, preview your handwriting as a real font, and export it as an installable `.TTF` or `.OTF` font.

## ✨ Features

- **Vector Drawing Canvas:** Smooth handwriting capture with pen/eraser tools, adjustable sizes, and typography guides (ascender, baseline, etc.).
- **70 Essential Characters:** Supports uppercase, lowercase, numbers, and basic punctuation.
- **Live Font Preview:** Test your font in real-time with custom sentences before downloading.
- **Easy Export:** Download as standard `.TTF` or `.OTF` files ready to install on Windows, macOS, and use in design apps (Word, Photoshop, Figma, etc.).

## 🚀 How to Use

1. **Start a Font:** Give your project a custom name.
2. **Draw Characters:** Select characters from the matrix and draw them on the canvas. Write naturally and use guides for consistency.
3. **Preview:** Test your handwriting live with sample text like _"The quick brown fox jumps over the lazy dog."_
4. **Generate & Install:** Export your font, double-click the file to install it on your OS, and select it in your favorite app.
